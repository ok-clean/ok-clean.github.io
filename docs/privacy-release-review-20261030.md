# PR #57 개인정보 개정안 승인 전 확인표 — 33차

상태: 시행 전 정책 초안. 기술 검증 통과와 실제 운영 배포 승인 가능 여부를 구분한다.
`privacy.html`의 초안 표시는 미확정 사실을 공개해도 법정 고지가 충족된다는 뜻이 아니다.
필수 사실을 확정해 생성 코드와 페이지를 함께 수정한 후에만 시행일과 최종 승인을 부여한다.
이 문서는 Pages 배포 제외 경로인 docs에 보관한다. 공개 Git 저장소이므로 개인정보·계정 식별자료를 적지 않는다.

- 상담 목적: 견적·서비스 문의 응대·후속 연락·일정 협의.
- 선택적 항목: 이름·연락처·청소 장소·현장 사진·기타 요청사항·청소 희망일. 매번 전부 수집하지 않는다.
- 상담 경로: 전화·문자·카카오톡 오픈채팅.
- 담당 부서: 오케이청소 개인정보 담당자, 033-911-4457. 운영자가 열람·정정·삭제의 실제 접수·처리 가능을 확인했다.
- 90일 원칙은 법적 보존 의무·삭제 가능 범위 확인을 조건으로 수용한 검토안이다. 법정 기간도 시행 중인 정책도 아니다.
- 고객 종료 의사 또는 견적·일정 협의 완료 후 추가 연락 불필요를 상담 종료 기준으로 검토한다. 장기 무응답 기준은 미확정이다.
- 신규 가입·홈페이지 예약·기존 회원 조회와 수정은 중지 상태를 유지한다. 기존 정보에 90일을 일괄 적용하거나 자동 삭제하지 않는다.

담당자는 확정 결과를 처리방침에 반영하고 권리 요청의 본인·대리권 확인, 처리 결과/제한 사유 통지 절차를 확정한다.
해당하는 자동 수집 장치·거부 방법, 안전조치, 처리방침 변경/시행일 등 나머지 필수 사항을 실제 운영과 대조한다.
위 항목이 남아 있는 동안 실제 운영 배포 승인 가능으로 판정하지 않는다. 운영자에게 동일한 사실의 재확인을 반복하지 않는다.

## 재사용한 운영 증거와 한계

운영자가 제공한 기존 확인: Firebase `okclean-admin`, Firestore `(default)` 컬렉션 표시 없음,
전체 표시 규칙 `allow read, write: if false;`, 현재 계정 Apps Script 전체 프로젝트 목록 비어 있음.
이는 해당 화면·계정의 확인 범위이며 데이터 부재, 다른 계정/저장소 부재 또는 Admin SDK/IAM 접근 부재를 증명하지 않는다.
Cloud Run·Functions 전체 운영, 다른 서버·외부 저장·백업은 미확정이다. 반복 Firebase 조사는 하지 않았다.
예약 서버 코드는 정적 배포 제외를 유지하며 PR #56은 변경하지 않는다.

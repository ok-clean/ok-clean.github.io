오케이청소 1단계: 지역 선택 + 비공개 회원관리 대장

1. 홈페이지 적용
  - 제공 ZIP 파일을 압축 해제합니다.
  - GitHub 저장소 ok-clean.github.io의 동일 파일들을 교체합니다.
  - 중요: build.py와 config.json을 함께 업로드해야 자동 업데이트 후에도 지역 목록이 유지됩니다.
  - 지역 선택은 견적 문의와 회원가입에서 강원 18개 시군 + 수도권 + 그 외 지역으로 나타납니다.
  - 기존 SEO 지역 페이지는 춘천·강원도·수도권 3개를 유지합니다.

2. 관리자 회원관리 대장 만들기
  - 개인 Google 계정에서 Google 스프레드시트 새 파일을 만들고 '오케이청소 회원관리'로 이름 지정합니다.
  - 스프레드시트 메뉴 [확장 프로그램] > [Apps Script]를 엽니다.
  - Code.gs 내용을 모두 복사해 기본 코드를 대체한 후 저장합니다.
  - Apps Script에서 setupSheet 함수를 한 번 실행하고 Google 권한을 승인합니다.
  - 시트에 '회원관리' 탭과 항목별 관리 열이 만들어집니다.
  - [배포] > [새 배포] > 유형 [웹 앱] 선택
  - 실행 사용자: 나 / 액세스 권한: 모든 사용자 (가입자 제출만 허용)
  - 배포한 웹 앱 URL 중 https://script.google.com/macros/s/.../exec 주소를 복사합니다.
  - config.json의 memberBackendUrl 값에 위 주소를 넣고 GitHub에 저장합니다.
  - 사이트 자동 생성(build.py 또는 GitHub Actions)이 끝나면 새 가입 정보가 비공개 시트에 기록됩니다.

3. 관리자 사용법
  - Google 스프레드시트는 본인 Google 계정만 접근하도록 공유 설정을 제한하세요.
  - 새 가입자는 행으로 쌓입니다.
  - 쿠폰상태: 미사용/사용/취소, 무료서비스상태: 미제공/제공완료/취소를 선택합니다.
  - 회원등급, 누적이용횟수, 누적결제금액, 포인트잔액, 상담상태, 관리메모를 직접 갱신합니다.
  - 회원혜택 기준은 config.json의 member.grades, member.pointTerms를 참고하세요.
  - 주의: 시트에서 바꾼 등급·포인트는 아직 고객 홈페이지에 자동 동기화되지 않습니다.

4. 중요 보안 및 운영 사항
  - 가입자 개인정보는 공개 GitHub 저장소에 저장하지 않습니다.
  - 웹 앱 URL은 누구나 가입 제출할 수 있는 공개 접수 창구입니다. 관리 화면은 비공개 시트입니다.
  - 웹 앱의 공개 입력에는 스팸·중복 가입 가능성이 있습니다. 쿠폰 사용 전 관리자 확인이 필요합니다.
  - 브라우저에서 Google 웹 앱의 응답을 확인하기 어려워 카카오톡 가입 완료 안내를 유지합니다.
  - memberBackendUrl이 빈 값이면 회원정보는 기존처럼 기기에만 저장되며 카카오톡으로 전달받아야 합니다.
  - 배포한 URL을 설정한 뒤 직접 테스트 가입하여 시트에 기록되는지 확인하세요.
  - 개인정보 삭제·정정 요청을 받으면 시트의 해당 행과 관련 기록을 직접 관리하세요.
  - Google Apps Script 할당량, 장애 또는 차단 시 자동 기록이 실패할 수 있습니다.

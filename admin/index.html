관리자 앱 설치

홈 화면에서 관리자 페이지를 바로 열 수 있습니다. 설치 후에도 관리자 로그인이 필요합니다.

안드로이드: Chrome 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가

아이폰·아이패드: Safari에서 이 주소 열기 → 공유 → 홈 화면에 추가 → 추가

카카오톡·네이버 앱에서는 설치창을 직접 띄울 수 없습니다. 아래 주소 복사 후 Chrome 또는 Safari 주소창에 붙여넣으세요.

이미 설치했다면 홈 화면 아이콘으로 실행하세요.

관리자 로그인

허가된 관리자 Google 계정만 회원정보를 볼 수 있습니다.

처음 설치할 때 Firebase 설정 및 관리자 UID 등록이 필요합니다.

회원 정보는 로그인한 관리자에게만 표시됩니다. 상담·쿠폰 변경은 저장 버튼을 누르세요.
